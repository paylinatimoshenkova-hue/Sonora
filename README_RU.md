# SONORA — инструкция по запуску

## Что это
Локальный прототип сайта на русском языке. Ты загружаешь свои аудиофайлы в библиотеку, записываешь фрагмент через микрофон и запускаешь сравнение.

**Важно:** это демонстрационный алгоритм, а не Shazam. Он сравнивает упрощённый звуковой профиль и может не найти нужный фрагмент или показать неверное совпадение.

## Что понадобится
- Компьютер Windows, macOS или Linux.
- Python 3.10 или новее.
- FFmpeg (нужен для чтения некоторых форматов, например MP3/M4A/WebM).
- Браузер с доступом к микрофону.

## Установка на Windows
1. Установи Python с https://www.python.org/downloads/ и при установке отметь **Add Python to PATH**.
2. Распакуй архив в отдельную папку.
3. Открой эту папку, щёлкни по адресной строке Проводника, напиши `cmd` и нажми Enter.
4. В чёрном окне выполни:
   `py -m pip install -r requirements.txt`
5. После установки выполни:
   `py app.py`
6. Открой в браузере адрес http://127.0.0.1:5000

## Установка на Mac
1. Установи Python 3 с https://www.python.org/downloads/.
2. Распакуй архив.
3. Открой Terminal и перейди в папку проекта командой `cd ` (после пробела перетащи папку проекта в окно Terminal и нажми Enter).
4. Выполни `python3 -m pip install -r requirements.txt`.
5. Выполни `python3 app.py`.
6. Открой http://127.0.0.1:5000 в браузере.

## Использование
1. В блоке «Добавь музыку» выбери свои аудиофайлы и загрузи их.
2. Обнови страницу, чтобы увидеть список загруженных файлов.
3. Нажми «Начать запись», проиграй нужный фрагмент рядом с микрофоном и нажми «Остановить».
4. Нажми «Найти совпадение».

## Примечания
- Для MP3/M4A/AAC и WebM может потребоваться FFmpeg, установленный отдельно.
- Микрофон обычно работает на localhost. Если браузер спросит разрешение, разреши доступ.
- Не закрывай окно терминала, пока пользуешься сайтом. Для остановки сервера нажми Ctrl+C.
